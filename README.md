# Post Hub

**Multi-forum platform · Angular · ASP.NET Core · SQL Server**

A full-stack web project bringing together discussion spaces, hierarchical user roles and media management, with an API documented through Swagger.

> **Repository status:** this public repository is a project showcase. Application source code and a runnable demo are not included here. This page describes the project presented in my CV.

## Project highlights

| Area | Functionality |
| --- | --- |
| Community spaces | A platform supporting multiple forums |
| Access control | Hierarchical user roles |
| Content | Media management |
| Backend | ASP.NET Core API with Swagger documentation |
| Data | SQL Server persistence |

## Technology stack

- **Frontend:** Angular, TypeScript
- **Backend:** ASP.NET Core, C#
- **Database:** SQL Server
- **API documentation:** Swagger

## Technical focus

The project combines a structured frontend, a server API and relational data. Its main areas of focus are role-based access, organizing discussion content and documenting API interactions.
